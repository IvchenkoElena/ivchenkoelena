### Немного обо мне (хотя многовато получилось):

Решила попробовать себя в программировании, пару лет назад начала изучать Java и поняла, что это то, что мне нужно, горю этим делом!

По характеру очень люблю докапываться на сути, не сдаюсь, пока не получится. Получаю колоссальное удовольствие, когда довожу проект до конца и вижу, как все работает.

Программированию училась на расширенном курсе Java-разработки Яндекс практикума, где опробовала новейшие и самые востребованные инструменты: Java Core, Spring, Spring Boot, Hibernate, Maven, SQL, Базы данных, Алгоритмы, Postman, Unit-теститрование, Mock-тестирование, Git, Scrum, Kanban, Микросервисная архитектура, Облачные среды, Docker, Spring Cloud, Config Server, Eureka , Gateway, Apache Kafka, Swagger, gRPC, Protobuf, Feign-клиенты, REST-API, DTO, Circuit Breaker, Load Balancer.

Всегда занимаюсь тем, что люблю, превращаю в работу то, чем увлечена, и занималась бы в любом случае, постепенно становлюсь в любимом деле профессионалом, очень много учусь. Java-разработка теперь стала для меня таким делом.

Ищу команду, где смогу быть полезной, учиться, расти профессионально как разработчик, выполнять интересные проекты.
